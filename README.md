# Microfrontend Learning Project

This repository is a learning project for exploring microfrontend architecture and Webpack Module Federation. It brings together applications built with React and Vue to demonstrate how independently developed frontend apps can work together.

## Applications

- `container` — the host application
- `marketing` and `auth` — React applications
- `dashboard` — a Vue application

Each application has its own `package.json` and dependencies. Install dependencies and run the scripts from the corresponding package directory.

This project is intended for learning and experimentation.
